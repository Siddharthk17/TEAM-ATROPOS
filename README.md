## 🎯 What is ATROPOS?

**ATROPOS** is a production-grade, **multi-agent AI financial intelligence system** built for people who want more than a pie chart. Upload any Indian bank statement — HDFC, SBI, ICICI, Kotak, Axis — and watch 4 specialized AI agents tear through your spending data in seconds.

Every agent speaks in **Pydantic-enforced JSON**. No hallucinations. No malformed output. Just ruthless, structured, actionable intelligence.

```
500+ transactions analyzed in under 5 seconds.
4 LLM calls. ~15K tokens. ~$0.001 cost. Zero crashes.
```

## 🚀 Quick Start

### Prerequisites
- **Python 3.11+**
- **Gemini API Key** — [Get one free](https://aistudio.google.com/)

### Run Locally

```bash
# Clone
git clone https://github.com/Siddharthk17/atropos-finance-ai.git
cd atropos-finance-ai

# Install dependencies
pip install -r requirements.txt

# Add your Gemini key
echo "GEMINI_API_KEY=your_key_here" > .env

# Launch
streamlit run app.py
```

### Run with Docker

```bash
docker build -t atropos-finance .
docker run -p 8501:8501 -e GEMINI_API_KEY=your_key_here atropos-finance
```

Then open **http://localhost:8501** — or hit **Demo Mode** instantly with no API key required.

## 📊 Supported CSV Formats

ATROPOS auto-detects columns from any Indian bank format. No manual mapping needed.

| Bank | Date Column | Amount Format | Tested |
|------|-------------|---------------|--------|
| **HDFC** | `Txn Date` | Separate Debit / Credit | ✅ |
| **SBI** | `Transaction Date` | `Withdrawal (Dr)` / `Deposit (Cr)` | ✅ |
| **ICICI** | `Value Date` | Single `Amount (INR)` | ✅ |
| **Kotak** | `Transaction Date` | Single `Amount` | ✅ |
| **Axis** | `Tran Date` | `Debit` / `Credit` | ✅ |
| **Any Other** | Auto-detected | Auto-detected | 🔍 |

## 🧠 Pydantic Schemas

ATROPOS enforces 6 schemas across every LLM call — zero tolerance for malformed output:

| Schema | Agent | Purpose |
|--------|-------|---------|
| `ColumnMapping` | Column Mapper | Maps raw CSV headers to standard fields |
| `CleanedTransaction` | Sanitizer | One cleaned merchant + category per transaction |
| `CleanedBatch` | Sanitizer | Batch wrapper for all cleaned transactions |
| `AnomalyItem` | Forensic Auditor | Single anomaly with type, severity, reasoning, evidence |
| `AnomalyReport` | Forensic Auditor | Full audit: all anomalies + risk score + summary |
| `WealthStrategy` | Wealth Architect | 3-step action plan + health score + verdict |
